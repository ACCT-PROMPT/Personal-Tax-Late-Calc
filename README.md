# 🇹🇭 เครื่องมือคำนวณภาษีค้างชำระ ค่าปรับ และเงินเพิ่ม (Tax Penalty & Surcharge Calculator)

เว็บแอปพลิเคชันแบบตอบโต้ (Interactive Web App) สำหรับคำนวณและวางแผนภาษีค้างจ่าย พร้อมคำนวณเบี้ยปรับ เงินเพิ่ม และค่าปรับทางอาญาของสรรพากรอย่างละเอียด พร้อมกราฟโดนัทจำลองโครงสร้างหนี้ภาษีที่สวยงาม

---

## 🚀 ฟีเจอร์เด่นของระบบ
- **คำนวณเบี้ยปรับและเงินเพิ่มอัตโนมัติ**: รองรับทั้งกรณี **ยื่นเพิ่มเติมด้วยตนเอง (สมัครใจ)** และ **กรณีโดนสรรพากรประเมิน**
- **จัดรูปแบบตัวเลขเรียลไทม์**: มีระบบใส่เครื่องหมายคอมม่า (`,`) ขณะพิมพ์อัตโนมัติ สะดวกต่อการใช้งาน
- **กราฟโครงสร้างหนี้ภาษี (Interactive Donut Chart)**: แสดงสัดส่วนภาษีหลัก ค่าปรับ และเงินเพิ่ม พร้อมป้ายบอกรายละเอียดที่ชัดเจนไม่ซ้อนทับกัน
- **คัดลอกสรุปข้อความ**: ปุ่มคัดลอกรายงานเพื่อส่งต่อหรือบันทึกได้ทันที
- **สตรีมไลน์ดีไซน์**: หน้าตาเว็บสวยงาม ทันสมัย ใช้งานง่าย รองรับการแสดงผลทุกหน้าจอ (Responsive Design)

## 💻 วิธีการติดตั้งและรันในเครื่องตัวเอง (Local Development)
ตรวจสอบให้แน่ใจว่าเครื่องของคุณติดตั้ง **Node.js** (เวอร์ชัน 18 ขึ้นไป) เรียบร้อยแล้ว

1. **เปิด Terminal / Command Prompt** เข้าไปยังโฟลเดอร์ที่แตกไฟล์ไว้:
   ```bash
   cd path/to/your/project-folder
   ```

2. **ติดตั้งไลบรารีที่จำเป็น (Dependencies)**:
   ```bash
   npm install
   ```

3. **รันโปรเจกต์ในโหมดพัฒนา (Development Mode)**:
   ```bash
   npm run dev
   ```
   *ระบบจะแสดง URL บนหน้าจอ (โดยทั่วไปคือ `http://localhost:3000` หรือ `http://localhost:5173`) ให้ใช้เบราว์เซอร์เปิดลิงก์ดังกล่าวเพื่อทดลองใช้งาน*

4. **สร้างไฟล์พร้อมใช้งานบนระบบจริง (Build for Production)**:
   ```bash
   npm run build
   ```
   *คำสั่งนี้จะสร้างโฟลเดอร์ชื่อ `dist` ซึ่งบรรจุไฟล์ HTML, CSS, JavaScript ที่ถูกย่อขนาดและปรับแต่งให้พร้อมไปเปิดใช้งานบนเว็บโฮสติ้งจริงได้ทันที*

## 🐙 วิธีนำโค้ดขึ้น GitHub เพื่อเก็บและแชร์

คุณสามารถนำโปรเจกต์นี้ขึ้น GitHub ได้ **2 วิธีหลักๆ** ดังนี้:

### วิธีที่ 1: อัปโหลดผ่านหน้าเว็บเบราว์เซอร์ของ GitHub (สำหรับมือใหม่ - ง่ายที่สุด)
1. ไปที่เว็บไซต์ [GitHub](https://github.com/) และเข้าสู่ระบบของคุณ
2. คลิกปุ่ม **New** (หรือคลิกเครื่องหมาย `+` มุมขวาบนแล้วเลือก **New repository**)
3. ตั้งชื่อ Repository (เช่น `tax-penalty-calculator`), เลือกเปิดเป็น **Public** จากนั้นคลิกปุ่ม **Create repository**
4. ในหน้าถัดมา มองหาหัวข้อ "Get started by creating a new file or uploading an existing file" แล้วคลิกที่ลิงก์ **uploading an existing file**
5. **ลากและวาง (Drag & Drop)** ไฟล์และโฟลเดอร์ทั้งหมดจากโปรเจกต์ของคุณ (ยกเว้นโฟลเดอร์ `node_modules` และ `dist` หากมี) ลงในพื้นที่ของหน้าเว็บ
6. เมื่อไฟล์อัปโหลดเสร็จ ให้เลื่อนลงมาล่างสุด คลิกปุ่ม **Commit changes** เป็นอันเสร็จสิ้น!

### วิธีที่ 2: ใช้ Git CLI ผ่าน Terminal (สำหรับนักพัฒนา - เป็นมืออาชีพ)
1. สร้าง Repository ใหม่บน GitHub โดยไม่ต้องเปิดสร้างไฟล์อื่นๆ เช่น README หรือ `.gitignore`
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์ของคุณในเครื่อง
3. พิมพ์คำสั่งต่อเพื่อตั้งค่าและส่งโค้ดขึ้น (แทนที่ `URL-ของ-Repository` ด้วยลิงก์ GitHub ของคุณ):
   ```bash
   # เริ่มต้นสร้าง Git ในโปรเจกต์
   git init

   # เพิ่มไฟล์ทั้งหมดเข้าสู่เตรียมการ Commit
   git add .

   # บันทึกความเปลี่ยนแปลงครั้งแรก
   git commit -m "initial commit: tax penalty calculator"

   # เปลี่ยนชื่อสาขาหลักเป็น main
   git branch -M main

   # เชื่อมโยงไปยัง GitHub Repository ของคุณ
   git remote add origin URL-ของ-Repository

   # ดันโค้ดขึ้นสู่ GitHub
   git push -u origin main
   ```

## 🌐 วิธีนำแอปนี้ขึ้นใช้งานบนเว็บไซต์ออนไลน์ฟรี (Web Hosting Deployment)
เนื่องจากโปรเจกต์นี้สร้างด้วย **React + Vite (Single Page Application)** คุณสามารถนำขึ้นระบบคลาวด์เพื่อให้คนทั่วไปเข้ามาใช้งานได้ **ฟรี 100%** ผ่านผู้ให้บริการยอดนิยมเหล่านี้:

### 1. ยื่นขึ้น Vercel (ง่ายที่สุดและแนะนำ)
1. สมัครใช้งานและเข้าสู่ระบบ [Vercel](https://vercel.com/)
2. คลิก **Add New...** -> **Project**
3. เลือกเชื่อมต่อกับบัญชี GitHub ของคุณ และเลือก Repository โปรเจกต์ภาษีนี้ขึ้นมา
4. ระบบจะตรวจจับว่าเป็นโปรเจกต์ **Vite** อัตโนมัติ (แทบไม่ต้องปรับแต่งเพิ่ม)
5. คลิกปุ่ม **Deploy**
6. รอประมาณ 30 วินาที คุณจะได้ลิงก์หน้าเว็บจริง (เช่น `your-project.vercel.app`) สามารถแชร์ให้เพื่อนๆ เข้ามาใช้งานได้เลย!

### 2. ยื่นขึ้น Netlify
1. เข้าใช้งานที่ [Netlify](https://www.netlify.com/)
2. เลือก **Import from Git** หรือหากสร้างไฟล์ผ่านคำสั่ง `npm run build` มาแล้ว คุณสามารถ **ลากและวางโฟลเดอร์ `dist`** เข้าไปยังช่องอัปโหลดหน้าเว็บ Netlify ได้โดยตรงเพื่อเปิดใช้งานทันที!

### 3. ยื่นขึ้น GitHub Pages
หากต้องการให้เว็บอยู่บนโดเมนของ GitHub โดยตรง (เช่น `username.github.io/tax-penalty-calculator`):
1. ติดตั้งแพ็กเกจช่วยติดตั้งหน้าเว็บโดยพิมพ์: `npm install gh-pages --save-dev`
2. เปิดไฟล์ `vite.config.ts` และเพิ่มบรรทัด `base: '/ชื่อ-Repository-ของคุณ/',` เข้าไปในส่วน config
3. เข้าไปเพิ่มสคริปต์ใน `package.json` ภายใต้หัวข้อ `"scripts"`:
   ```json
   "predeploy": "npm run build",
   "deploy": "gh-pages -d dist"
   ```
4. พิมพ์คำสั่งรันใน Terminal เพื่อ Deploy ขึ้นทันที:
   ```bash
   npm run deploy
   ```
