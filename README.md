# ระบบคิดค่าปรับภาษีเงินได้บุคคลธรรมดา และ ภ.พ.30

เว็บคำนวณเบี้ยปรับ เงินเพิ่ม และค่าปรับอาญา กรณียื่นภาษีล่าช้า ชำระไม่ครบ หรือถูกประเมิน
มี 2 แท็บ คือภาษีเงินได้บุคคลธรรมดา (ภ.ง.ด.90/91) และภาษีมูลค่าเพิ่ม (ภ.พ.30)
การคำนวณและประวัติทำงานในเบราว์เซอร์ ไม่ส่งข้อมูลภาษีหรือไฟล์ไปเก็บบนเซิร์ฟเวอร์
หน้าใช้งานจริงอยู่บน Cloudflare Workers และต้องเปิดผ่านบัญชี ACCT Prompt ที่มีสิทธิ์โปรแกรม

เว็บจริง: https://tax-late-calc.acctprompt.com

## ฟีเจอร์

- คำนวณเบี้ยปรับ เงินเพิ่ม ค่าปรับอาญา ภ.ง.ด.90/91 และ ภ.พ.30 ตัวเลขทุกจุดมีคอมม่าและทศนิยม 2 ตำแหน่ง ปัดเศษเป็นสตางค์
- **ตัวช่วยคำนวณภาษีจากรายได้** แยกตามอาชีพ/ประเภทเงินได้ 40(1)-(8) หักค่าใช้จ่ายตามกฎของแต่ละประเภท ค่าลดหย่อนตามเพดาน และภาษีขั้นต่ำ 0.5%
- แยก **วันที่ยื่นแบบ** (ตัดสินค่าปรับอาญา) ออกจาก **วันที่ชำระ** (นับเงินเพิ่ม) และกำหนด **วันครบกำหนดเอง** ได้ เช่น กรณีมีประกาศขยายเวลา
- **ดาวน์โหลด Excel**: ผลการคำนวณรายการเดียว (ตัวแปรเป็นช่องสีเหลืองแก้ได้ ทุกยอดเป็นสูตร และมีแผ่น "ที่มาของภาษี" เมื่อใช้ตัวช่วยคำนวณรายได้) หรือประวัติทั้งหมดในตารางเดียว
- **ประวัติการคำนวณ**: บันทึกพร้อมชื่อลูกค้า/เลขอ้างอิง เปิดกลับมาคำนวณใหม่ ลบ และส่งออกได้ เก็บในเบราว์เซอร์ของเครื่องนั้น
  (localStorage, สูงสุด 200 รายการ) ไม่ส่งข้อมูลไปที่ใด ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่องประวัติจะหาย จึงควรดาวน์โหลด Excel เก็บไว้

## หลักเกณฑ์ที่ใช้คำนวณ

| รายการ | กฎ | อ้างอิง |
|---|---|---|
| เงินเพิ่ม | 1.5% ต่อเดือน (เศษของเดือนนับเป็น 1 เดือน) ของภาษี ไม่เกินยอดภาษี | ประมวลรัษฎากร ม.27 (VAT: ม.89/1) |
| เบี้ยปรับ ภ.ง.ด. (ถูกประเมิน) | ยื่นไม่ครบ 1 เท่า, ไม่ยื่น 2 เท่า ลดได้ตามดุลพินิจแต่ไม่ต่ำกว่า 50% | ม.22, ท.ป. 81/2542 ข้อ 4 |
| เบี้ยปรับ ภ.ง.ด. (ยื่นเอง) | ไม่มีเบี้ยปรับ มีเฉพาะเงินเพิ่มและค่าปรับอาญา | |
| เบี้ยปรับ ภ.พ.30 (ยื่นเอง) | 2% / 5% / 10% / 20% ของเบี้ยปรับตามกฎหมาย เมื่อช้าไม่เกิน 15 / 30 / 60 วัน / เกิน 60 วัน | ท.ป. 81/2542 ข้อ 5(1) |
| เบี้ยปรับ ภ.พ.30 (ถูกประเมิน) | เต็ม 100% หรือลดเหลือ 40% / 50% ตามดุลพินิจ | ท.ป. 81/2542 ข้อ 5(2)-(3) |
| ค่าปรับอาญา | ภ.ง.ด. ไม่เกิน 2,000 บาท (ม.35) จำนวนจริงตามที่สรรพากรแจ้ง จึงให้ผู้ใช้กรอกเอง | |

คำสั่ง ท.ป. 81/2542 ฉบับแก้ไขโดย ท.ป. 369/2569 (มีผล 3 ก.ค. 2569)
ตรวจสอบกับเว็บกรมสรรพากรล่าสุดเมื่อ 26 ต.ค. 2569: https://www.rd.go.th/3361.html
ผลลัพธ์เป็นการประมาณการ ควรยืนยันกับเจ้าหน้าที่ก่อนชำระจริง

## โครงสร้าง

```text
src/App.tsx              หน้าจอหลักและฟอร์ม
src/utils/taxCalc.ts     สูตรคำนวณทั้งหมด (เบี้ยปรับ เงินเพิ่ม อัตราก้าวหน้า)
src/utils/incomeTax.ts   ตัวประเมินภาษีตามประเภทเงินได้ 40(1)-(8)
src/utils/format.ts      จัดรูปแบบตัวเลข (คอมม่า ทศนิยม)
tests/calc.test.ts       ชุดทดสอบสูตร (npm test)
src/utils/history.ts     ประวัติการคำนวณ (localStorage)
src/utils/excel.ts       ส่งออกไฟล์ Excel (ExcelJS โหลดเมื่อกดส่งออก)
src/types.ts             ชนิดข้อมูล
src/components/          กราฟโดนัท ตัวเลขแอนิเมชัน แถบภาษีก้าวหน้า
public/fonts/            ฟอนต์ (Poppins สำหรับ A-Z/0-9, LINE Seed Sans TH สำหรับภาษาไทย)
worker/index.js          ตรวจ launch ticket และสิทธิ์สมาชิกก่อนส่งไฟล์แอป
wrangler.jsonc           Cloudflare Worker และ Static Assets
.github/workflows/       workflow สร้างและเผยแพร่ artifact
```

## รันในเครื่อง

ต้องมี Node.js 22 ขึ้นไป

```bash
npm ci
npm run dev      # http://localhost:3000
npm run lint     # ตรวจชนิดข้อมูล
npm test         # ทดสอบสูตร (รันใน CI ทุกครั้งก่อน build)
npm run build    # ได้โฟลเดอร์ dist
```

## Deploy บน Cloudflare

ใช้ `npm run deploy:cloudflare` เพื่อ build และ deploy Worker พร้อมไฟล์ใน `dist` ไปยังบัญชี Cloudflare ที่ระบุใน `wrangler.jsonc`.
Worker จะแลก launch ticket แบบใช้ครั้งเดียวกับ `acctprompt.com` และตั้ง cookie แบบ HttpOnly สำหรับ session ของโปรแกรม
หากไม่มีสิทธิ์หรือสิทธิ์หมดอายุ จะไม่ส่งหน้าแอปให้ใช้งาน

ประวัติและการคำนวณยังอยู่ใน `localStorage` ของเบราว์เซอร์ ไม่ได้สำรองข้ามอุปกรณ์และไม่มีข้อมูลภาษีฝั่ง server
